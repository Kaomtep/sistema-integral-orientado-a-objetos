## Descripción

Sistema desarrollado en Python aplicando los principios de la **Programación Orientada a Objetos** para la gestión integral de:

- **Clientes** (con validaciones y encapsulación)
- **Servicios** (Sala, Equipo y Asesoría – herencia y polimorfismo)
- **Reservas** (integración de cliente + servicio + duración + estado)

El sistema incluye:

- Clase abstracta base (`Entity`)
- Métodos sobrecargados para el cálculo de costos
- Manejo avanzado de excepciones (personalizadas, `try/except/else/finally` y encadenamiento)
- Registro de eventos y errores en archivo de log
- Más de 10 operaciones válidas e inválidas sin que el programa se detenga
- Sin uso de base de datos (solo objetos y listas en memoria)
